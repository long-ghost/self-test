## 2026-11-24 新增 Git 自助安装与更新（v1.1.0）

- **来源**：使用者反馈「新用户只拿到 Git 地址，希望 AI 自己装、自己查更新」；原 README 依赖未提交的 `dist/` zip，git 用户拿不到安装物。
- **改动**：`install.ps1` / `check-update.ps1` / `update.ps1` 三脚本 + `.install.json` 安装记录；同步以上游仓库为准、保留 4 个本地配置；SKILL 增加「仅在用户要求时手动检查更新」与「升级只在两轮之间」约定。
- **待观察**：不同终端编码下 git 输出是否正常；缓存目录与技能目录分离是否够直观；代理/离线环境下的更新检查降级是否写清。
