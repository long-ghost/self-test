# 技能演进日志

> 只记有证据的改进，append-only。格式与判定见 `references/retrospective.md`。
> 合并进技能后才升版本；本文件本身不决定版本号。

## 2026-11-24 报告说明行与图例优化（v1.2.1）

- **来源**：用户要求结论说明更明显、缺陷数可跳转到明细、证据条图例不换行。
- **改动**：`report_html.py` 将说明行拆成指标块，有缺陷时缺陷数为 `#defects` 锚点；按 `bugs.json` 生成内联缺陷明细；图例改四列网格并取消 `<br>`。
- **待观察**：缺陷字段中存在超长接口响应时会拉高明细区；后续如影响阅读，可改为折叠块。

## 2026-11-24 报告增加整轮耗时（v1.2.0）

- **来源**：用户要求测试报告显示这次测试耗时；选择“整轮耗时”口径，从确认档位与范围到报告定稿。
- **改动**：报告模板与 SKILL 首部新增 `测试耗时`；HTML 顶栏显示总耗时，旧报告显示“耗时未记录”；`check-report.ps1` 校验格式、时间顺序与分钟数；agent 摘要与模板同步要求。
- **待观察**：执行者是否会按真实时间记录而不是估算；自检只能校验字段内部一致性，不能证明时钟真实。

## 2026-11-24 新增 Git 自助安装与更新（v1.1.0）

- **来源**：使用者反馈「新用户只拿到 Git 地址，希望 AI 自己装、自己查更新」；原 README 依赖未提交的 `dist/` zip，git 用户拿不到安装物。
- **改动**：`install.ps1` / `check-update.ps1` / `update.ps1` 三脚本 + `.install.json` 安装记录；同步以上游仓库为准、保留 4 个本地配置；SKILL 增加「仅在用户要求时手动检查更新」与「升级只在两轮之间」约定。
- **待观察**：不同终端编码下 git 输出是否正常；缓存目录与技能目录分离是否够直观；代理/离线环境下的更新检查降级是否写清。

## 2026-11-24 初始公开版（v1.0.0）

- **来源**：从本机自测技能通用化而来，目标是独立维护与发布，不绑定具体项目。
- **改动**：保留七步流程、28 条规则、需求确认、CSV 账号、HTML 报告、缺陷记录；项目配置、真实账号、责任人映射和内部复盘改为示例/模板。
- **待观察**：首次初始化探测是否覆盖主流工程结构；不同项目接入时是否需要扩展 `project-profile.example.md` 字段。
