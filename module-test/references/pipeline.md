# 链路三验：业务流程 / 数据流程 / 业务逻辑

**功能点全绿不等于模块能用。** 这三层必须单独列验收点，且只有 L2 / L3 能验——L1 只能确认调用链接上了、字段映射对了。

## 先画链路图（贴进报告第一节）

```
入口（谁 / 哪一页）
  → 操作（填什么 / 点什么）
  → 接口 A（写入）
  → 表 X（字段齐不齐：主键 / 审计字段 / 软删标记）
  → ETL（任务名 / 频率 / 口径）
  → 表 Y 或数仓
  → 接口 B（读取）
  → 页面展示（单位 / 精度 / 口径）
  → 下游（导出 / 钻取 / 其他模块引用）
```

**链路画不出来就别开测**——说明业务没吃透，先回去读代码和 plan。

## 业务流程

- 找出完整闭环：角色 → 入口 → 操作 → 中间态 → 终态 → 结果被谁消费
- 按闭环逐步走，**不许跳步**（跳步只证明某一段能跑）
- 跨页状态：URL 参数、全局状态、年份记忆、页签定位、返回路径
- 中断重入：中途刷新、中途切组织、退出再进
- 反向流程：删除 / 撤销 / 驳回 / 退回，状态是否真回退、下游是否同步
- 多角色接力：A 填 → B 审 → C 看，换账号后可见性与数值
- 边界入口：菜单进、消息进、其他页钻取进、直接敲 URL，四条路径结果一致

## 数据流程

- **逆推血缘**：页面字段 → 接口 → Service → Repository → 表/视图 → ETL → ODS/ADS → 源系统
- **值要对得上**：源表取一个具体值，一路查到页面，不是「看着差不多」
- 换算只做一次：元/万元、小数/百分比、个/万
- 口径核对：累计 vs 存量、去重 vs 累加、本级 vs 含下级 vs 全量、当月 vs 上月 vs 跨年
- 时效核对：数据截止日、页面默认展示哪个月、缺数据如何表现
- 写入链路：必填、主键、审计字段、软删标记、回滚后有无脏数据
- **同一指标在报表 / 看板 / 导出 / 钻取四处必须同值**

> 典型坑：数仓某月只产出了 `notax` 口径、缺 `operating`，页面静默显示 `--`，业务会当成 0。缺月要先查库再定性。

## 业务逻辑

- 计算：分母为 0、四舍五入位数、负值、合计行是否被重复计入
- 状态机：只允许合法流转，且非法流转在**接口层**被拦（不是仅前端藏按钮）
- 权限：低权限账号**直接打接口**验越权
- 组合条件：多筛选同时生效、互斥项、清空某项后其余项行为
- 幂等与并发：重复提交、双击、并发改同一行
- 时序约束：先有 A 才有 B（先立项才有订单、先有工单才有入库）

## 判定

每层至少产出一张表（# / 验收点 / 期望 / 实测 / 证据 / 判定）。三层都为空，说明只跑了功能点。
