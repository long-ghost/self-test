# CRUD 全量覆盖（按模块能力裁剪）

## 先判模块类型

判定依据是**后端有没有写入口**，不是页面有没有按钮：

```powershell
Select-String -Path <模块 Controller 目录>\*.java -Pattern "@(Post|Put|Delete)Mapping"
```

| 类型 | 判定 | 用例规模 |
|---|---|---|
| 只读 | 只有 GET，页面无新增/编辑/删除 | 跳过 CRUD，报告写明「无写操作」+ 判定依据 |
| 单表 CRUD | 有 POST/PUT/DELETE，无明细表 | 四类全跑（下表 31 项） |
| 主子表 | 有明细随主表保存 | 追加事务与级联项 |
| 带审批 | 有状态字段与流转接口 | 追加状态迁移矩阵 |

## Create 新增（9 项）

| # | 检查项 |
|---|---|
| C1 | 全字段填满 → 成功，且**查库确认每个字段真的落了** |
| C2 | 必填字段**逐个单独缺失** → 均被拦住，提示到具体字段 |
| C3 | 唯一键重复 → 可读提示，不是 500 或数据库异常栈 |
| C4 | 默认值：未填字段落库符合预期（状态、排序、创建人、创建时间） |
| C5 | 主键生成正确（16 位雪花、不重复、非自增回填） |
| C6 | 主子表：主表失败子表不落；子表失败主表回滚 |
| C7 | 越界值与非法枚举（**直接打接口验**，绕开前端） |
| C8 | 重复提交 / 双击 → 幂等，只落一条 |
| C9 | 无权限角色调接口 → 403，不是 200 |

## Read 查询（7 项）

| # | 检查项 |
|---|---|
| R1 | 空结果 / 单条 / 多条（≥3 条验证排序） |
| R2 | 分页：首页、末页、超页、`pageSize` 上下限、`pageNum=0` |
| R3 | 默认排序稳定；切换排序；传非法排序字段 |
| R4 | 单条件筛选、成对组合、无匹配、清空条件 |
| R5 | 模糊搜索特殊字符 `% _ ' \`、前后空格、大小写 |
| R6 | 数据范围：本级 / 含下级 / 跨部门不可见 |
| R7 | 敏感字段脱敏或不出现在响应 |

## Update 修改（8 项）

| # | 检查项 |
|---|---|
| U1 | 全字段改 / 单字段改，**查库比对**（不看页面回显） |
| U2 | 唯一键改成已存在的值 → 拦住 |
| U3 | 不存在的 id → 业务提示，不是 500 |
| U4 | 越权改他人数据 → 拦住 |
| U5 | 传入主键 → 被忽略，不允许改主键 |
| U6 | 审计字段：`update_time` / `update_by` 更新，`create_*` 不被覆盖 |
| U7 | 状态机禁止的字段 → 拦住 |
| U8 | 并发：两会话同时改，行为明确（乐观锁报错或后写覆盖），不能静默丢更新 |

## Delete 删除（7 项）

| # | 检查项 |
|---|---|
| D1 | 单条删 / 批量删 |
| D2 | 软删除：标记正确、数据仍在、列表不可见、详情是否可访问口径明确 |
| D3 | 被引用数据：拦住并提示引用位置，或按既定规则级联 |
| D4 | 重复删同一条 → 幂等 |
| D5 | 删不存在的 id → 明确提示 |
| D6 | 越权删他人数据 → 拦住 |
| D7 | 软删后唯一键能否复用（同名再建） |

## 写操作必须走完整链路

```
页面提交 → 查库确认落库（含审计字段、软删标记、主键）→ 回列表看展示 → 详情读回
```

只看到 toast 成功就下结论，是最高频的漏测。
