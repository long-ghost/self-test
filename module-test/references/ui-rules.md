# 界面与交互规范核对（六类）

**业务对不代表能交付。** 规则来源按优先级：`AGENTS.md` → `<project-rules>/`（`theme.md` / `ui-layout.md` / `chart.md` / `report-table.md` / `component-library.md` / `vue-page.md`）→ 用户级规则文件。

开测前先把命中的规则文件读进来，按条款列表，不要凭印象。

## 6.1 配色

- 页面 `<style>` 的背景 / 文字 / 边框 / 圆角 / 阴影是否全走 `var(--el-*)` / `var(--zc-*)`，有没有新写死 `#fff` / `#303133`
- 图表 hex 只允许出现在 `option` 内（canvas 不消费 CSS 变量），不许扩散到模板与 `<style>`
- 同一指标跨页是否同色；BU / 产品线 / 等级 / 新老客是否走既有色组常量，而不是按 series 下标取色（过滤 0 值后必错位）
- 语义色是否复用：计划 / 实绩 / 累计 / 目标各有固定色，不许同图里绿蓝混用
- 阈值色：达成率偏差 ±20% 才着色，合计行不判定

## 6.2 交互

- 筛选变化是否自动重查（不设「查询」按钮），有没有「改了筛选还显示旧数据」
- 切页签是否重置筛选并重取，遮罩时长是否够
- loading 初值是否 `true`（防闪空态）；失败是否落空态而不是弹全局错误、是否用 0 / 空数组兜底
- 按钮是否带 `:loading` + `:disabled`，重复点击会不会发多次请求
- 切部门 / 切年份后，下拉、弹窗、分页是否残留上一组状态
- 下钻与返回：是否透传必要参数、回到原页签与原年份、有没有裸 `router.back()`
- 浏览器后退键行为是否符合预期

## 6.3 下拉框 / 选择器

- 默认值是否正确（如「营销中心默认选中且不传 deptId」这类口径）
- 必选项清空后回退默认还是报错，是否与同模块其他页一致
- 选项顺序、分组、禁用项；当前已选项是否可辨
- 切换后是否触发重查、是否重置下级联动项
- 长选项是否会撑破工具栏 / 换行错乱

## 6.4 列表 / 表格

- 工具栏是否用统一组件，左右分区是否正确，有没有自写工具栏
- 「报表数据查询 / 导出 / 列设置」是否齐全，导出是否带当前筛选、文件名是否含关键维度
- 列设置：同一份 `columns` 是否同时给表头与表体，显隐记忆是否**按表隔离**（同名列不串味），刷新是否回全显
- 冻结列：左冻到序号、右冻到累计；宽度不足时是否退化为只冻左侧
- 数值格式：金额位、客数位、百分比位是否统一；空值与 0 的展示是否符合本模块约定
- 分页：报表页是否默认不分页；钻取表每页条数与序号是否跨页连续
- 空态文案是否统一；表头底色、hover 色、线框色是否合规
- 合计行是否保留且加粗加底色，是否被误算进图表
- 行内操作按钮的权限与禁用态

## 6.5 图表

- 类型是否匹配数据关系（趋势→折线、构成→堆叠柱、占比→环饼、目标达成→柱+线双轴）
- 双轴：左数量/金额、右金额/累计，右轴不画柱，两轴 `min:0`
- 轴上限是否自适应（`niceAxisMax`），有没有写死业务常量
- 图例位置、项数超限是否滚动
- tooltip：白底自定义还是默认数组式；抬头与明细行字号；空值 `--`
- 空值是否保持 `null` 断开（`connectNulls:false`），有没有 0 填充、`NaN`、`--%`
- 点数 >12 是否有 `dataZoom`，>20 是否关掉柱顶合计
- 饼图占比是否取后端 `value`（不是 `params.percent`，过滤 0 值后会重算错）
- 空数据是否显示 `ElEmpty` / 灰色空心环，而不是空白矩形
- 切换筛选后图表是否真正重绘，有无残留上一个系列的图例

## 6.6 输入框 / 表单

- 必填校验时机（blur / change）与提示文案是否统一
- 长度限制是否与 DB 列宽对齐（见 `consistency.md`）
- `trim` 是否生效，纯空格能不能提交；数字框能否输负号、科学计数、超精度
- 回车是否提交、重复提交是否被拦
- 只读 / 禁用态是否可辨，禁用时是否仍发请求
- 粘贴富文本 / emoji / 全角字符
- 整体校验与局部校验是否一致

---

每条规则都要在报告里占一行，判定写「符合 / 不符合（差异）」+ 截图或代码位置。**没有截图或行号的「符合」不算数。**
